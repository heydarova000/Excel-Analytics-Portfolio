# Sales & Movie Performance Analysis | Excel Dashboard

## Project Overview

This project is an interactive Excel-based data analysis portfolio focused on Sales Analysis and Movie Performance Analysis.

The project demonstrates the complete data analysis workflow, including data exploration, data cleaning, cleaning documentation, Pivot Table analysis, and interactive dashboard development using Microsoft Excel.

## Project Structure

### 1. Sales Dashboard
An interactive dashboard designed to monitor and analyze sales performance through key metrics and visualizations.

**Key Features:**
- Sales performance overview
- KPI analysis
- Interactive charts and visualizations
- Business performance monitoring

### 2. Data
Contains the original raw dataset used throughout the project for analysis and reporting.

### 3. Data Cleaning
Includes the cleaned dataset after processing and preparing the raw data for analysis.

**Key Activities:**
- Identifying and handling missing values
- Removing duplicate records where necessary
- Correcting data inconsistencies
- Formatting and standardizing data
- Preparing data for analysis

### 4. Data_Cleaning_Log
Documents the data cleaning process and records the changes made to the original dataset.

### 5. Pivot Tables (Pivot 1–4)
Four Pivot Table sheets created to summarize, organize, and analyze the data from different perspectives.

**Purpose:**
- Summarizing sales data
- Comparing business performance
- Identifying trends and patterns
- Supporting dashboard visualizations

### 6. Movie Performance Dashboard
An interactive dashboard focused on analyzing movie performance and presenting insights through visual reports.

**Key Features:**
- Movie performance analysis
- Comparative data visualization
- Key performance indicators
- Interactive reporting
